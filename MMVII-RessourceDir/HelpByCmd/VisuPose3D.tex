\SecDescr

This command creates a $3$D visualisation of poses and also, possibly,
a sparse visualisation of the scene (using tie points).
The visualisation is made using a point cloud in \FileSty{ply} format, because
it can be read very easily by various free open source software.

The camera poses are visualized using a pyramid for a rectilinear camera and
a set of ``meridians'' for a fisheye or a lidar station
(see Figure~\ref{fig:VisuPose3D}; a picture is worth a thousand words).

%=============================================================================

\section{Fixing the size of the pyramid}

The size of the pyramid is proportional to the $35$\,mm focal length
(precisely, the focal length in pixels divided by the diagonal of the image).

The default rule to compute this proportionality factor uses the parameter
\FileSty{ELPFD}\footnote{Evaluate Length Pyramid From Depth \dots}
and the tie points:

\begin{itemize}
  \item a depth $D$ is computed using a proportion of all the depths of all
        tie points (default $30\%$);
  \item this depth $D$ is multiplied by a factor (default $\frac{1}{10}$).
\end{itemize}

If the parameter \FileSty{CamScale} is set, it is used instead of the
previous computation. The default value of \FileSty{CamScale}
($\frac{1}{10}$) is also used if there are no tie points.
